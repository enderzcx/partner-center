# 结算台返佣比例展示

本页只约定结算台如何展示返佣比例。结算服务接收已经算好并冻结的佣金，不按比例重算，也不提供比例编辑。

## 规则

- 海外默认 10%，可按邀请人覆盖；显式 `0` 关闭新返佣。
- 按实际支付金额计算。赠送、试用与收益转入不计返佣。
- 比例在下单时确定。之后调整只作用于新订单，不影响已冻结或已出款金额。
- 当前页展示的是来源给出的现行比例说明，不是对已有结算单重新计费。

## 本应用

| 来源 | 展示 |
| --- | --- |
| 演示 fixture | 固定 `0.1`，标明演示规则。不是真实来源政策。 |
| BeefAPI 测试适配 | 读取同一 `GET /api/settlement-test/partners/:id` 中的 `commission_rate`（0 到 1 的小数字符串）和 `commission_rate_source`（`default` / `override` / `disabled`）。 |
| 缺字段、格式无效、来源不可用 | 比例为无法读取，不回退成 10%。有效余额仍展示。 |
| 显式 `0` | 展示 0%。当前不产生新返佣；已生成的付款继续处理。 |

`/api/demo/commission` 的输入是已计算的佣金，不是订单实付。

开启 `SETTLEMENT_ORDER_DEMO` 时，测试订单的返佣金额以来源返回的 `commission_usdc` 为准。结算台不按当前展示比例重算，也不接受浏览器提交的金额、比例或收款地址。
