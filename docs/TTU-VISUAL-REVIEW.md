# 伙伴中心视觉与 TTU 专项验收

2026-09-19，用户明确要求全面检查字体、框线及其他可见问题并修正。本轮以实际渲染为准，保留海外站迁移结构；范围为首页、登录、说明、商家与推广者总览、订单、钱包、结算记录和回执。没有运行资金操作或部署。

## 已发现并修复

- 总览指标、表头及状态沿用了9–10px字号，部分灰字对比约3.47:1，首页回执辅助字约2.72:1。提升有效小字至12px，修正灰字颜色；保留原字体与层级。
- 各控制台标题分别44px/500与34px/650，部分副标题继承浏览器默认16px/normal。统一为桌面34px/600、移动28px/600及14px/1.7副标题；中文不再套拉丁负字距。
- 首页懒加载CSS覆盖早期中文修正。新增限定作用域的partner-visual.css，保证异步载入后仍生效。CDP实际字体读回：拉丁及金额Schibsted Grotesk，地址Geist Mono，中文标题PingFang SC，未靠font-family声明推断。
- 面板1px细框和14px圆角、输入区10px圆角收口，保留海外站胶囊按钮；去掉表格末行与外框叠线；金额列右对齐、数值等宽对齐。菜单箭头、焦点框不再沿用不适合浅色界面的颜色。
- 移动刷新按钮从隐藏恢复为可用，标题与操作行允许换行；指标两列排列。大金额999,999.999998布局探针不裁切、不四舍五入，320px视口未产生横向溢出。
- 回执金额实际被组件p规则压成正文，已纠正为32px并分离币种间距。关闭按钮移到顶部，金额/状态/地址优先，单号与完整链上字段可展开。保持展开状态跨轮询不丢失；Escape关闭和模态焦点已验证。
- 登录标题“伙伴中心”被拆词，改为语义分行。首页底部品牌行取消nowrap和过大字号，避免320px裁切。减少动态效果模式直接显示各段，不再依赖滚动观察器。
- 修正订单页“下方结算记录”错误位置指引、钱包“当前来源”等内部用语、钱包金额单位缺失，以及AVAX单位孤行。首页控制台图更新为修正后的实际画面。
- 手机导航的Tab保持在打开的菜单与关闭按钮内，Escape关闭后回到菜单按钮；事件监听随菜单关闭移除。
